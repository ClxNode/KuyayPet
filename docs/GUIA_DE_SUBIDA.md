# Guía rápida para publicar KuyayPet en GitHub

1. Crea un repositorio (por ejemplo, `KuyayPet`) o abre el repositorio donde presentarás el proyecto.
2. Sube **el contenido de la carpeta `KuyayPet-GitHub`**, manteniendo exactamente sus subcarpetas; el archivo `README.md` debe quedar en la raíz del repositorio.
3. Verifica que las imágenes estén en `assets/branding/` y `assets/diagrams/` con los mismos nombres.
4. Abre la página principal del repositorio: GitHub mostrará automáticamente el `README.md` con el banner, el logo y el diagrama SVG.
5. Al comenzar a subir código, crea carpetas `historias-de-usuario/HU-XX/` y documenta cada implementación usando `PLANTILLA_HU.md`.
6. Actualiza `docs/historias-de-usuario.md` y el apartado de avance del README solo cuando el trabajo esté realmente desarrollado o validado.

**Importante:** No copies únicamente el texto de `README.md` sin subir también `assets/`: las imágenes dejarían de mostrarse.

**GitHub:** los gráficos SVG incluidos son archivos locales y no requieren alojar imágenes en servicios externos. Los distintivos de colores (badges) sí requieren acceso a `shields.io` para mostrarse.
